Key setup and troubleshooting
  1. Enable Maps JavaScript API and Geocoding API in the same billing-enabled Google Cloud project.
  2. Use a browser key restricted to the website URL serving this file, and restrict it to those two APIs.
  3. For a local copy with website restrictions, serve its folder with python -m http.server 8000, open http://localhost:8000/NYC-CRE-Portfolio-Map.html, and allow http://localhost:8000/* on your key.
  4. For production hosting, use your own Google Map ID. If you change keys after loading Google, reload this page first.

Source & definitions

Source: $510MM NYC Performing CRE Loan Portfolio_Overview_DV.xlsx
Data Tape rows 3–80; Pivot Table thresholds S4:S5.

Population78 loans, 90 reported properties, 98 explicitly listed address locations. All states and markets are included.
Workbook flagNOI debt yield < 7.0% OR NOI DSCR < 1.00×, matching the pivot’s conditional formatting.
Any flag / past dueWorkbook flag OR Days Late > 0. There are 36 matching loans, including six showing 11–25 days late.
Distress screenNegative NOI OR 30+ days late. This is an analytical screen. The tape does not provide a confirmed default, nonaccrual, watchlist or special-servicing status.
Low occupancyOccupancy < 90%, an additional screening threshold separate from the workbook's flags.
Shared collateralEach map pin points to a loan record. Where a loan lists multiple addresses, units, SF, vintage, occupancy, NOI, UPB, DY and DSCR are reported for the entire tape row. No allocation among locations is assumed. Header statistics and CSV count each loan once.
AddressesSemicolon lists and explicit street-number lists are expanded. Address ranges remain one query; aliases are retained in source text. The Allentown campus is one reported property with six street addresses. Extra street numbers account for the remaining differences.
UPB / NOI / DYCurrent UPB (F), NOI (AR), and NOI Debt Yield (AT) are copied from the tape. Filtered DY = total NOI ÷ total UPB. Source reporting periods vary; each record shows its NOI and occupancy dates.
Units / SF / vintageMultifamily Units (AL), Commercial NRA (AK), Year Built (AN). Commercial NRA excludes residential area. “—” means the source is blank or “-”, not zero. Values are retained as supplied, including the 46 SF entry for loan 140027.
Location qualityGoogle matches are checked for country, state, street number, partial matches and precision. Ambiguous, approximate or multiple results are held for review rather than plotted automatically. A match is a geocoding result, not a verified parcel boundary.
